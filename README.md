
# Local Storage in JavaScript

A practical JavaScript project that demonstrates how to use the browser's Local Storage API to create a simple authentication system.

## Features

* User Registration (Sign Up)
* User Login (Sign In)
* Data Storage using Local Storage
* Form Validation
* Responsive Modern UI
* Beginner-Friendly Code Structure

## Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API
* SweetAlert2

## Project Structure

```text
├── signup.html
├── signin.html
├── app.js
├── style.css
└── README.md
```

## How It Works

1. Users create an account using the Sign Up form.
2. User credentials are stored in the browser's Local Storage.
3. Users can log in using the registered credentials.
4. Validation checks ensure proper authentication.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/local-storage-in-js.git
```

2. Open the project folder.

3. Run `signup.html` in your browser.
